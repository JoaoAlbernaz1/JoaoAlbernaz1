# Hugging Face Space · dashboard de pesquisa BANKING77-PTBR

Website estático, monocromático e responsivo para mostrar um experimento reproduzível de NLP. Possui gráficos alternáveis de validação, resultados de teste oficial e auditoria de textos repetidos.

- O modelo executável está em [BANKING77-PTBR Intent v1](https://huggingface.co/JOAOOALBERNAZ/banking77-ptbr-intent-v1).
- Os resultados provêm de um treino verificado no GitHub Actions, documentado no [relatório técnico](../docs/banking77-ptbr-results.md).
- O **Space é estático** e **não oferece inferência do modelo**. Seu objetivo é tornar os resultados técnicos navegáveis para recrutadores e pesquisadores.
- O SDK static não utiliza instância Gradio/Docker paga.
